# edwinnava.github.io

Personal portfolio for Edwin Nava — Systems Administrator focused on cybersecurity.
Live at **https://edwinnava.github.io**.

## Structure

- `index.html` — all page content (about, experience, projects, certifications, skills, contact)
- `css/styles.css` — styles; colors are CSS variables at the top of the file
- `js/scripts.js` — mobile menu, scroll effects, and active-section highlighting (no dependencies)
- `Edwin_Nava_Resume.pdf` — resume served by the "Download Resume" buttons
- `libs/font-awesome` — icon font

No build step: edit the files and push to `main`, and GitHub Pages publishes the site.
The contact form is handled by [Formspree](https://formspree.io/).

Originally based on [devportfolio-template](https://github.com/RyanFitzgerald/devportfolio-template) by Ryan Fitzgerald (MIT).
